# AsiCohen

A simple static digital business project submitted by Ori Peretz.

## 🚀 How to Run

You can easily run this project locally using Python's built-in HTTP server. No additional dependencies are required.

1. **Clone the repository:**
   ```
   git clone https://github.com/Ori-Pe/AsiCohen.git
   cd AsiCohen
   ```

2. **Start the local server:**
   Open your terminal in the project directory and run the following command:
   ```
   python -m http.server 8080
   ```

3. **View the project:**
   Open your web browser and navigate to:
   http://localhost:8080
